# A fazenda

[Português](README.md) | **English**

A **Unity 6** **2D** project with the **Universal Render Pipeline (URP)**, created from Unity's 2D template. "A fazenda" is Portuguese for "the farm".

> **Status: not started.** The repository only contains the freshly created project: the sample scene with the default camera and 2D light. There are no C# scripts and no game content yet.

## Tech stack

- **Unity** 6000.5.4f1 (Unity 6 line)
- **Universal Render Pipeline** 2D
- Packages from Unity's 2D template (Input System, 2D Animation, Tilemap Extras and others), listed in `Packages/manifest.json`

## Structure

```
A-fazenda/
├── Assets/
│   ├── Scenes/SampleScene.unity   # template sample scene
│   └── Settings/                  # URP 2D settings
├── Packages/manifest.json         # project packages
└── ProjectSettings/               # project settings (ProjectVersion.txt)
```

## How to open

1. Install **Unity Hub** and the **6000.5.4f1** editor (or a compatible Unity 6 version).
2. In Unity Hub, click **Add** and select the repository folder.
3. Open the scene `Assets/Scenes/SampleScene.unity`.
